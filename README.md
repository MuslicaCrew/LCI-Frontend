# LCI-Frontend

## Backend 
This project heavily relies on the [LCI project](https://github.com/MuslicaCrew/LCI) (backend). 

## Requirements
To run the application you need to install the latest Microsoft Visual C++ Redistributable runtime

## Build
To build the project and get an EXE run the following command
```
dotnet publish -c Release
```
## Running the application
Inside the win-x64/Publish folder run the EXE file to run the application
